# Nova Arena

Juego web 3D original desarrollado con
JavaScript y Three.js.

## Estructura

- `index.html`
- `css/`
- `js/core/`
- `js/player/`
- `js/weapons/`
- `js/enemies/`
- `js/world/`
- `js/ui/`
- `js/systems/`

## Características

- Mundo 3D
- Personaje controlable
- Sistema de vida
- Armas
- Enemigos
- Inventario
- Objetos recogibles
- HUD
- Menú principal
- Sistema básico de partida

## Tecnología

- HTML
- CSS
- JavaScript
- Three.js
